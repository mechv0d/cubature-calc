# Картинки справочника

Все картинки лежат в этой папке — `app/assets/guide/`.

## Главное

**На каждую статью нужны две картинки:**

- `<slug>-square.jpg` — квадрат для списка справочника (превью 116 × 116,
  показывается целиком, без обрезки);
- `<slug>.jpg` — широкая 16:9 для шапки самой статьи.

Если квадратной версии нет, из широкой вырежется центр — тоже сработает,
но лучше положить отдельный квадрат.

## Размеры

- **Квадрат: 512 × 512** (минимум 256 × 256, максимум 1024 × 1024).
  Предмет занимает 60–75 % кадра, иначе в мелком превью он «утонет».
- **Шапка: 16:9, 1600 × 900** — оптимально. Подойдёт и 1200 × 675,
  и 1920 × 1080. Вертикальные кадры не годятся: в шапке от них останется
  полоска.
- Вес одного файла — до 400 КБ (всё это едет внутри APK).

Ваши `guide-01.jpg` и `guide-02.jpg` (1672 × 941) подходят как широкие
версии: переименуйте их в `measure.jpg` и `tochkovka.jpg`.

## Картинки внутри текста (не обязательно)

Если нужно вставить картинку между абзацами статьи, положите её сюда же
и укажите в Markdown отдельной строкой:

```markdown
![Подпись под картинкой](guide/inline-diameters.png)
```

Готовые имена для таких вставок:

| Файл | Где уже используется в тексте |
| --- | --- |
| `inline-diameters.png` | «Как мерить кругляк по ГОСТ» |
| `inline-stack-factor.png` | «Складочный и плотный кубометр», «Дрова» |
| `inline-board-cube.png` | «Сколько досок в кубе» |
| `inline-density.png` | «Породы и масса» |
| `inline-rounding.png` | «Таблица ГОСТ 2708-75» |

Пропорции — 4:3 (например 1080 × 810). Ширина подстроится под экран,
углы скруглены. Подпись берётся из `alt`; если она не нужна — оставьте `![]()`.
Фон лучше светлый, под цвет страницы `#FBF6E9`.

Если картинки нет — ничего не сломается: покажется серая заглушка, статья
откроется.
