ГОСТ 2708-75 содержит таблицу для определения объёма круглых лесоматериалов — отдельных брёвен и партий леса. Для расчёта используются два параметра: толщина бревна, измеренная по верхнему (тонкому) торцу, и его длина. На пересечении соответствующих значений в таблице указан объём одного бревна в кубических метрах.

Приложение использует значения непосредственно из этой таблицы, а не рассчитывает объём самостоятельно по геометрической формуле. Поэтому при совпадении исходных измерений результат приложения соответствует значению, которое можно получить по бумажному кубатурнику ГОСТ 2708-75.

## Какие значения содержит таблица

В таблице предусмотрены следующие диапазоны:

- **Толщина бревна:** от 4 до 100 см.
- **Длина бревна:** от 1,0 до 9,5 м с шагом 0,1 м.
- **Объём:** указан в кубических метрах с точностью до 0,001 м³.

Каждое значение относится к одному бревну с указанными толщиной и длиной. Чтобы получить общий объём партии из одинаковых брёвен, достаточно умножить объём одного бревна на их количество. Если в партии брёвна разных размеров, объём каждого размера следует определить отдельно, а затем сложить полученные значения.

## Как определить объём бревна в приложении

Для работы с таблицей понадобятся два измерения. Сначала измерьте толщину верхнего, то есть более тонкого, торца бревна. Результат указывается в сантиметрах. Затем измерьте длину бревна в метрах.

После ввода этих данных приложение находит в таблице ГОСТ 2708-75 соответствующую пару значений и показывает объём одного бревна. Этот объём уже приведён в кубических метрах, поэтому для расчёта партии из нескольких одинаковых брёвен его остаётся умножить на количество штук.

## Почему объём не рассчитывается по формуле цилиндра

Бревно нельзя считать идеальным цилиндром: его диаметр меняется по длине. Это изменение называется **сбегом** — к вершине ствол обычно становится тоньше, чем у комля. В исходном описании для сбега приводится ориентировочная величина 0,8–1 см на каждый метр длины.

Из-за этой особенности расчёт по формуле цилиндра не отражает форму реального бревна. Особенно заметным будет завышение, если в качестве исходного размера взять диаметр комля — более толстой части. Таблица ГОСТ 2708-75 использует толщину верхнего торца, то есть меньший диаметр бревна, и задаёт объём по установленным табличным значениям.

Поэтому приложение не заменяет таблицу собственной геометрической оценкой: оно выбирает готовое значение из кубатурника по введённым толщине и длине.

## Что происходит, если нужной комбинации нет в таблице

Таблица охватывает не все возможные сочетания толщины и длины. Для тонких брёвен в ней могут отсутствовать значения для большой длины, а для толстых — для короткой. Это ограничение самой таблицы, а не ошибка измерения или расчёта приложения.

Если для введённых толщины и длины нет соответствующей ячейки, приложение не пытается вычислить приблизительный объём и не подставляет ближайшее значение. Вместо этого оно показывает диалоговое окно и предлагает выбрать другую длину или толщину, для которых в таблице есть данные.

## Важное замечание о приёмке леса

Табличный расчёт объёма — это справочная часть работы с лесоматериалами, но сам по себе он не заменяет процедуру приёмки и измерения. Если объём, полученный в приложении, расходится с точковкой поставщика, причину расхождения следует выяснять по результатам измерений и применяемым правилам учёта.

Для измерения лесоматериалов используется ГОСТ 2292-88, а для определения объёма по толщине и длине — таблица ГОСТ 2708-75. Окончательное решение при расхождении данных должно опираться на измерения и соответствующие нормативные документы, а не только на результат приложения.
