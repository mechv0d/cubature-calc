# Калькулятор кубатуры

Мобильное приложение на Flet.

## ГОСТ 2708-75 · Таблица 1

Экран повторяет рабочую компоновку из предоставленного образца:
- слева — список добавленных брёвен;
- справа — цифровая сетка диаметров;
- внизу — сохранение расчёта и выбор длины;
- нажатие на диаметр сразу добавляет одно бревно с текущей выбранной длиной;
- повторное нажатие на тот же диаметр добавляет отдельную позицию;
- диаметр не имеет состояния выбора и не подсвечивается зелёным.

Объёмы берутся из проверенной таблицы `app/data/gost_2708_table_1.json` через `app/calculators/gost_2708.py`. Если для введённых диаметра и длины в таблице нет значения, приложение показывает диалог с кнопкой «Закрыть».

## Разработка

Версия Flet закреплена на `0.86.0`, Python — `3.13`.

Локальная установка:

```bash
python -m pip install -r requirements.txt
python main.py
```

## CI и APK

GitHub Actions запускает:
1. компиляцию Python;
2. Ruff;
3. smoke-тесты интерфейса;
4. сборку Android APK только для `arm64-v8a`;
5. публикацию APK в Artifacts.

Workflow находится в `.github/workflows/main.yml`.
