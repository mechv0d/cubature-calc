# Кубатура Экспресс

Кроссплатформенный офлайн-калькулятор кубатуры лесоматериалов на **Flet**.
Работает как приложение для Android (APK), десктопное приложение и веб-страница.
Все расчёты и данные хранятся на устройстве — интернет не требуется.

## Возможности

- **ГОСТ 2708-75 · Таблица 1** — объём круглых лесоматериалов по проверенной
  таблице (диаметры 3–100 см, длины от 1 до 9,5 м). Если для пары
  «диаметр + длина» значения нет, показывается диалог с пояснением.
  Брёвна с одинаковыми диаметром и длиной объединяются в одну позицию,
  а нажатие на позицию открывает окно изменения количества (0–1000 шт.)
- **Итоги расчёта** — общий экран для ГОСТ и оцилиндровки: сводная таблица
  с группировкой по диапазонам цен, итоговой кубатурой и общей стоимостью.
  Стоимость показывается и для каждой позиции, и для итога диапазона.
  Кнопка «i» показывает количество брёвен, минимальный/максимальный/средний
  диаметр, контрагента и цену 1 м³. Итоги можно скачать или отправить как
  Excel-таблицу, а также сохранить в партию.
- **Настройки расчёта** — цены по диапазонам (стандартные 3–11, 12–17,
  18–120, один диапазон или свои), показ диаметров (все, чётные, нечётные),
  порода, тип расчёта и контрагент, выбранный заранее. Работают одинаково
  в ГОСТ и оцилиндровке.
- **Пиломатериалы** — расчёт досок и бруса по размерам
  (толщина × ширина × длина), с единицами измерения мм / см / м,
  количеством, ценой за м³ и настраиваемым округлением (до 6 знаков).
  Поддерживаются редактирование, дублирование и удаление позиций.
  Нажатие на количество открывает редактор сразу на этом поле. У новой
  позиции курсор стоит на толщине, а стандартные «0»/«1» выделяются: первая
  введённая цифра заменяет их, а не дописывается («05» → «5»).
- **Оцилиндровка** — объём оцилиндрованного бревна по формуле цилиндра,
  настраиваемое округление и тот же экран «Итоги», что и в ГОСТ.
- **Партии** — сохранение расчётов в локальную базу, карточка партии с
  составом, итогами, контрагентом и описанием; редактирование и удаление.
  В карточке видны объём, количество и общая сумма партии, а в составе —
  стоимость каждой позиции. Если цена не задана, вместо неё стоит «—».
  Контрагент выбирается из справочника; его можно добавить прямо в диалоге
  создания партии. Название обязательно, а повторное сохранение с тем же
  названием обновляет телефон, email и дополнительную информацию.
  Расчёт ГОСТ по умолчанию называется «Кругляк д.мм» (например,
  «Кругляк 26.11»), а длинное описание в списке партий обрезается до трёх
  строк. Размер картинки в карточке задаётся константой `PARTY_ICON_SIZE`
  в `main.py` (по умолчанию 70 px); карточка использует обычный `Row`,
  потому что `ListTile` ограничивает `leading` примерно 56 px и картинка
  уменьшалась бы.
- **Контрагенты** — отдельный экран со списком контрагентов (телефон, email,
  дополнительная информация), добавлением, редактированием и удалением.
- **Точковка PDF** — экспорт партии в PDF (A4, кириллица) с итоговой таблицей.
  На десктопе файл сохраняется в каталог данных, в вебе скачивается на
  устройство, а на Android/iOS сразу открывается системное окно «Поделиться».
  То же самое делает кнопка «Расчёт Excel».
- **Справочник** — восемь статей о приёмке леса (ГОСТ 2708-75, измерение
  кругляка, складской и плотный кубометр, дрова, доски, точковка, источники,
  породы и масса). Тексты — Markdown-файлы, картинки можно вставлять между
  абзацами; внизу списка — справка о том, что приложение неофициальное.
- **Черновики** — незавершённый расчёт автоматически сохраняется и
  восстанавливается после перезапуска приложения или телефона.
- **Удобство на телефоне** — удержание экрана включённым во время расчёта,
  тактильный отклик при добавлении позиции, адаптивная сетка диаметров
  (2–4 колонки в зависимости от ширины экрана).
- **Системная кнопка «Назад»** — работает как в нативном приложении:
  «Итоги» → таблица расчёта, расчёт → главный экран, партия → список партий,
  контрагенты → список партий, статья → справочник. Открытый диалог
  закрывается, редактор расчётов партии закрыть нельзя (только «Отмена» или
  «Сохранить»), а на главных экранах для выхода нужно нажать «Назад» дважды
  (с предупреждением и окном 2 секунды). Логика — в `app/navigation.py`.

## Технологии

| Компонент | Версия / примечание |
| --- | --- |
| Python | 3.13 |
| Flet | 0.86.0 |
| OpenPyXL | ≥ 3.1 (экспорт Excel) |
| ReportLab | ≥ 4.0 (экспорт PDF) |
| SQLite | встроенный модуль `sqlite3` |
| Хранилище данных | `calculations.sqlite3` на устройстве |

## Установка и запуск

```bash
python -m pip install -r requirements.txt
python main.py
```

`main.py` запускает нативное приложение Flet (окно на десктопе).

Веб-версия:

```bash
python web.py
```

Приложение будет доступно на `http://localhost:3000`.

## Справочник: как добавить или поправить статью

1. Текст статьи — файл `app/content/guide/<slug>.md`. Доступны заголовки
   `##`/`###`, абзацы, списки, цитаты (`>`), линии (`---`), а внутри текста —
   `**жирный**`, `*курсив*`, `` `код` `` и ссылки `[текст](адрес)`.
2. Картинка между абзацами — отдельной строкой:
   `![Подпись под картинкой](guide/inline-name.png)`. Ширина подстраивается под
   экран, подпись берётся из `alt` и выводится под картинкой.
3. Сама картинка кладётся в `assets/guide/` (каталог `assets` рядом с
   `main.py`). Форматы, размеры и имена файлов — в `assets/guide/README.md`.
4. Новая статья — это пара файлов в `app/content/guide/`: `<slug>.md` с текстом
   и `<slug>.json` с полями `title`, `subtitle`, `order` и `active`
   (`false` скрывает статью из списка). Картинки `<slug>-square.png` (список)
   и `<slug>.png` (шапка) подхватятся по имени.

Если картинки нет, приложение покажет заглушку и продолжит работать.

## Как считаются объёмы

- **ГОСТ 2708-75**: значения берутся из `app/data/gost_2708_table_1.json`
  через `app/calculators/gost_2708.py`. Объём позиции — табличное значение
  на количество, округление до 0,001 м³.
- **Пиломатериалы**: `толщина_см / 100 × ширина_см / 100 × длина_м × кол-во`.
  Каждая позиция округляется отдельно, затем значения суммируются.
  Стоимость — объём × цена за м³. В составе партии позиция показывается
  в миллиметрах без слова «Пиломатериал», например `50×50 мм`.
- **Оцилиндровка**: `π × (диаметр_м / 2)² × длина_м × кол-во`,
  округление с настраиваемой точностью.

PDF-точковка — справочный документ. Он не заменяет первичный учётный
документ без подписи сторон.

## Хранение данных

- Каталог данных: `FLET_APP_STORAGE_DATA`, если переменная задана, иначе
  текущий рабочий каталог.
- Файл базы: `calculations.sqlite3` (таблицы `parties`, `counterparties`,
  `drafts`, `calculations`).
- На десктопе PDF-файлы сохраняются в тот же каталог данных.
- В вебе PDF и Excel формируются в памяти и передаются клиенту через файловый
  диалог, поэтому на сервере ничего не остаётся. На мобильных те же файлы
  передаются в системное окно «Поделиться».
- Файлы `*.sqlite3`, `*.pdf` и артефакты сборки исключены из Git.

## Тесты и проверка кода

```bash
python -m pip install flet==0.86.0 "openpyxl>=3.1" pytest ruff
python -m compileall -q main.py app tests
ruff check main.py app tests
python -m pytest -q
```

Тесты не требуют реального окна: они работают с настоящими контролами Flet
через тестовую страницу и временную базу SQLite. Покрыты главный экран,
добавление брёвен, значения из таблицы ГОСТ, диалог отсутствующего значения,
сохранение/восстановление черновиков и сервисы удержания экрана.

## Сборка Android APK

Локально (нужен Android SDK и зависимости Flet):

```bash
flet build apk --yes --python-version 3.13 --arch arm64-v8a
```

Готовый файл появится в `build/apk/`.

### Статика и иконка

Flet ищет ресурсы в каталоге `assets`, который лежит рядом с точкой входа
(`main.py`), — именно его он упаковывает в APK. Поэтому:

- все картинки и шрифты лежат в `assets/` (а не `app/assets/`), а
  `ft.run(main, assets_dir="assets")` указывает на этот каталог;
- иконка приложения — `assets/icon.png` (квадратная, лучше 1024 × 1024).
  Ключ `icon` в `[tool.flet]` эта версия Flet не читает;
- если каталог называется иначе, файлы не попадут в сборку и в приложении
  будут видны только заглушки, а иконка останется стандартной.

## CI

GitHub Actions (`.github/workflows/main.yml`) на каждый push в `main`/`master`,
pull request и ручной запуск:

1. компилирует Python;
2. запускает Ruff;
3. выполняет pytest;
4. собирает APK только для `arm64-v8a`;
5. публикует APK в Artifacts (срок хранения — 14 дней).
