# Расчёт кубатуры — стартовый проект

Первый прототип мобильного приложения на Python + Flet.

## Что уже есть
- Главный экран с пятью разделами.
- Экран ГОСТ 2708-75 с вводом диаметра, длины и количества.
- Добавление и удаление позиций.
- Локальное сохранение расчётов в SQLite.
- Экран истории.
- Отдельная функция расчёта через импортированную таблицу.
- Пустой JSON-шаблон для таблицы ГОСТ.

## Важное ограничение
Табличные значения ГОСТ не добавлены: их нельзя достоверно восстановить по двум скриншотам. До получения проверенной таблицы приложение намеренно не показывает выдуманную кубатуру.

## Запуск на компьютере

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Сборка Android

Сборка Flet требует Android build dependencies. После установки Flet CLI и необходимых компонентов:

```bash
flet build apk
```
