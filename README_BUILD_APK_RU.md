# Как получить APK через GitHub (можно с телефона)

В проект уже добавлен GitHub Actions workflow `.github/workflows/build-apk.yml`.
После загрузки проекта в репозиторий GitHub автоматически запустит сборку APK.

1. Распакуйте ZIP проекта на телефоне.
2. Создайте пустой репозиторий на https://github.com/new (например, `cubature-calculator`). Не добавляйте README, LICENSE или .gitignore.
3. Загрузите в репозиторий **содержимое** папки `cubature_calculator` — включая скрытую папку `.github`. Если мобильный браузер не позволяет загрузить папки целиком, откройте GitHub в режиме «Версия для ПК» или воспользуйтесь GitHub Codespaces.
4. Откройте вкладку **Actions** в репозитории. При первом использовании GitHub может попросить подтвердить включение Actions.
5. Дождитесь завершения задания **Build Android APK** со статусом зелёной галочки.
6. Откройте завершённый запуск workflow, прокрутите до **Artifacts** и скачайте `cubature-calculator-apk`. Внутри будет APK (или архив сборки, если формат выхода изменится в Flet).

Если сборка завершится красным крестиком, откройте её и пришлите мне текст ошибки или скриншот журнала.

Важно: это пока стартовый прототип интерфейса. Таблица ГОСТ 2708-75 в проекте оставлена пустым шаблоном, поэтому реальные значения кубатуры ещё не рассчитываются. Сборка APK сама по себе не добавляет отсутствующие нормативные данные.
